屏幕管家 Windows 1.6.3

1. 解压整个压缩包，双击 ScreenPilotBridge.exe。无需旧文件夹、编译器或管理员权限。
2. 首次打开选择共享显示器（Mac HDMI 1 / Windows HDMI 2）。已有配置会自动保留。
3. 点击“安装到本机并创建桌面入口”，之后从桌面的“屏幕管家”打开，下载文件夹可以删除。
4. USB 局域网自动切换：选择共享键盘/鼠标接口与条件，再勾选启用。Mac 端也要单独设置。
   USB接入通过已配对局域网通知另一主机切屏；需要两端新版和网络配对。拔出/启动不切屏；自动切到Windows保持Mac布局。
5. “设置开机启动”会先保存程序到本机目录，再登记当前用户登录启动；可在窗口取消。
6. USB联动需要网络配对。已有配对可保留；没有配对时，在窗口配置地址并复制配对码到 Mac。

关闭窗口会收起到系统托盘。完全退出请右键托盘图标选择“退出”。
更新前请先退出旧程序。配置存在 %APPDATA%\ScreenPilotBridge，程序安装在 %LOCALAPPDATA%\ScreenPilotBridge。

适用 Windows 10/11（需要 .NET Framework 4.8）。本程序未购买代码签名证书。
首次显示器选择/USB设备识别不能安全地自动猜测；每端设置一次后按保存的规则工作。
显示器须支持并开启 DDC/CI；非当前输入的控制是否被接受取决于显示器，仍需实机验证。
若出现雪花屏，停止自动切换，按此前有效的方法重插 Mac HDMI 恢复，并导出诊断。

网络连接还在但不能上网：从托盘完全退出软件作对照。运行 Network-Diagnostics.cmd 只读检查并把桌面报告交给排查人员；不修改网络设置。
