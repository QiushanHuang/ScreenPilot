# ScreenPilot v1.6.4 · 待发布 / Unreleased

## 中文

- 重新整理 Mac 显示器、预设、主机切换、配对和诊断界面，减少重复说明，让当前状态、主要操作和恢复入口更清楚。补充信息通过可访问的信息按钮查看。
- 优化浅色、深色和窄窗口布局，补充显示器亮度、操作按钮和导航状态的辅助功能名称。
- 新建停止输出预设默认使用 15 秒自动恢复；删除预设或场景、替换配对，以及 Windows 安装或开机启动可能覆盖现有文件时，会先说明后果。
- 配对码无效时保留输入；主机切换页显示操作结果，未配置共享显示器时提供配置入口。Windows 配对设置取消后不再误报保存成功，更改配对后提示重新启动。
- 修正 Windows 界面中 USB 自动切换不需要网络配对的错误说明。网络诊断入口说明会访问 Microsoft 并在桌面保存报告。

**验证范围：** Mac 使用模拟设备检查界面和主要交互；Swift、原生控制保护和 Windows 核心测试，以及 Windows 交叉编译和打包检查通过。尚未进行 Windows 图形界面实机验收，也未执行实体显示器控制、恢复或跨主机切换测试。公共构建不包含个人显示器映射；跨主机联动仍需按硬件配置指南实测并配置。

## English

- Simplifies the Mac display, preset, host-switching, pairing and diagnostics screens while keeping status, recovery and accessible controls visible. Supplemental details are available through accessible information buttons.
- Improves light, dark and narrow-window layouts and accessibility labels for display controls and navigation.
- New output presets default to 15-second recovery. Deletion, pairing replacement, and Windows install/startup actions that may overwrite existing files explain their consequences before proceeding.
- Invalid pairing codes remain in the field. The host-switching screen shows command feedback and a setup entry for unconfigured monitors. Cancelling Windows pairing setup no longer reports a successful save, and changed pairing settings prompt for a restart.
- Corrects the Windows claim that USB automation works without LAN pairing. The network diagnostics action explains its Microsoft connection and desktop report.

**Validation scope:** Mac UI and key interactions were checked with simulated displays. Swift, native control-safety and Windows core tests, Windows cross-compilation and packaging checks passed. Windows GUI behavior, physical display controls/recovery and cross-host switching have not been validated on real hardware. Public builds exclude personal monitor mappings; host switching still requires a locally tested configuration.
