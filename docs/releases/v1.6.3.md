# ScreenPilot v1.6.3

First public GitHub release by **[QiushanHuang · Qiushan](https://github.com/QiushanHuang)**.

Native Mac display controls, brightness/blackout scenes, recoverable output presets and an optional Windows companion. This release brings both platforms to version 1.6.3, adds the original paired-display logo, and replaces outdated instructions with a bilingual README using same-page language badges.

## Downloads

- macOS arm64: DMG installer and ZIP app bundle, macOS 14+ deployment target.
- Windows 10/11: ready-to-run companion (.NET Framework 4.8), plus a source/build-script ZIP.
- `SHA256SUMS.txt`: package checksums.

**Signing:** macOS is ad-hoc signed, not Developer ID signed or notarized. Windows is not Authenticode signed.

**Scope:** public packages contain no personal verified-monitor mappings. General Mac controls use detected capabilities; Mac/Windows host automation requires a locally tested mapping and rebuild, plus LAN pairing. See README and `docs/hardware-setup.md`. The UI is Simplified Chinese; documentation is bilingual.

**Validation:** local release-mode Swift tests; native DDC packet/control-safety tests; .NET Windows cross-build and production core self-tests; Windows package checks; macOS bundle signature verification. Physical display power/recovery, Windows GUI behavior and real cross-host USB switching are not certified by these checks.
